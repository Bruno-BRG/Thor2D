# thor2d.Transforms

Transforms provide explicit 2D translation, rotation, scale and raw affine
matrix operations. Points can be converted in both directions; matrix overrides
are preserved until a TRS setter clears them.

The implementation and every public signature are listed in
[Api_Reference](../Api_Reference.md). For LOVE ports, see the transform rows in
[Porting From LOVE](../guides/Porting_From_LOVE.md).
